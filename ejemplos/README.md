# Ejemplos

## plan-simple.json

Plan de parcheo a un solo archivo.

    node toolkit.mjs apply ejemplos/plan-simple.json

## plan-multi.json

Plan de parcheo a múltiples archivos, transaccional.

    node toolkit.mjs apply ejemplos/plan-multi.json

## simbolos.txt

Lista de símbolos para `refs-multi`.

    node toolkit.mjs refs-multi ejemplos/simbolos.txt --dir src
